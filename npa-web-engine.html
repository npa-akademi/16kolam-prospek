Panduan Lengkap NPA Engine

1. Memahami 8 Engine (Jenis Website)

Setiap website punya "struktur bangunan" yang beda. Pilih sesuai kebutuhanmu:

  • Landing Page: Fokus jualan 1 produk. Struktur panjang ke bawah (Masalah, Solusi, Testimoni, Tombol Beli).
  • Toko Online: Web katalog dengan deretan gambar produk, harga, dan tombol Add to Cart.
  • Company Profile: Web resmi perusahaan. Menunjukkan kredibilitas, layanan, dan alamat kontak.
  • Portfolio/CV: Untuk pamer karya. Cocok buat desainer, agen properti, fotografer.
  • Undangan Digital: Khusus event/pernikahan. Dilengkapi countdown (hitung mundur) dan RSVP.
  • Link-in-Bio: Web seukuran layar HP (mirip Linktree) berisi tombol-tombol link penting.
  • Menu F&B: Katalog menu digital untuk Cafe/Resto lengkap dengan harga.
  • Halaman Jasa: Mirip Landing Page tapi fokus menampilkan "Tabel Paket Harga" (Basic/Pro/VIP).

2. Tutorial Mengisi Gambar via Postimage

Agar AI bisa langsung memasang logo atau gambarmu di dalam website, ikuti cara ini:

  1. Klik tautan Upload Postimage ↗ pada form di atas.
  2. Pilih dan upload gambarmu dari HP/Laptop.
  3. Setelah selesai, cari kolom yang bernama Direct link atau Tautan langsung.
  4. Copy (Salin) link tersebut (Biasanya berakhiran .png atau .jpg).
  5. Paste (Tempel) link itu ke kolom URL Logo atau URL Gambar Hero di NPA Engine.

3. Bedanya ChatGPT vs v0.dev vs Claude 3.5

Setelah mendapatkan teks prompt dari NPA Engine, kamu harus mem-paste teks tersebut ke AI Pembuat Kode. Mana yang terbaik?

  • v0.dev (Sangat Disarankan): AI khusus pembuat desain web (UI). Setelah kamu paste prompt, dia tidak cuma kasih kode HTML, tapi langsung memunculkan wujud websitenya di layar! Kamu bisa klik-klik dan edit langsung. Gratis dengan sistem kredit bulanan.
  • Claude 3.5 Sonnet: AI paling pintar untuk coding saat ini. Aktifkan fitur "Artifacts" di Claude, maka setiap kamu paste prompt, dia juga akan menampilkan "Preview" websitenya langsung di sebelah kanan layar. Gratis dengan limit.
  • ChatGPT (Biasa): Jika menggunakan ChatGPT biasa, dia hanya akan membalas dengan teks mentah (kode HTML hitam-putih). Kamu harus copy kode itu dan mem-paste-nya ke Github Pages/Notepad untuk melihat hasil websitenya.
